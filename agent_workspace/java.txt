Java 语言介绍
================

一、概述
Java 是一种广泛使用的、面向对象的高级编程语言，由 Sun Microsystems 公司的詹姆斯·高斯林（James Gosling）等人于 1991 年开发，1995 年正式发布。2009 年甲骨文公司（Oracle）收购 Sun 后，Java 现由 Oracle 负责维护和演进。

二、核心特点
1. 简单易学：去除了 C++ 中指针运算、多重继承等复杂特性，语法相对简洁。
2. 面向对象：一切皆对象（基本数据类型除外），支持封装、继承、多态。
3. 平台无关性：通过"一次编写，到处运行"（Write Once, Run Anywhere）的理念，编译后的字节码（.class）可运行在任何装有 Java 虚拟机（JVM）的平台上。
4. 垃圾回收（GC）：自动管理内存，回收不再使用的对象，降低内存泄漏风险。
5. 强类型、静态类型：编译期即可检查类型错误，提高程序健壮性。
6. 多线程支持：内置多线程机制，便于开发高并发程序。
7. 分布式与网络支持：内置丰富的网络编程类库，适合开发网络应用。
8. 安全性与健壮性：没有指针、强制类型检查、异常处理机制等保证程序安全。

三、运行机制
Java 源代码（.java 文件）首先由编译器（javac）编译为字节码（.class 文件），然后由 Java 虚拟机（JVM）加载并执行。JVM 可以通过解释执行或即时编译（JIT）的方式运行字节码，这正是 Java 跨平台的关键。

四、版本演进
- JDK 1.0（1996）：首个正式版本。
- J2SE 1.2（1998）：引入集合框架，分为 J2SE/J2EE/J2ME 三个版本。
- Java 5（2004）：引入泛型、注解、枚举、增强 for 循环等。
- Java 8（2014）：引入 Lambda 表达式、Stream API、函数式接口，是一个里程碑版本。
- Java 11（2018）：成为长期支持版本（LTS）。
- Java 17（2021）：LTS 版本，引入密封类（Sealed Classes）等特性。
- Java 21（2023）：LTS 版本，正式引入虚拟线程（Virtual Threads）。
此后 Java 保持每 6 个月一个版本、每两年左右一个 LTS 版本的发布节奏。

五、应用领域
1. 企业级后端开发：Spring、Spring Boot、Jakarta EE 等框架广泛用于服务端开发。
2. 移动开发：Android 应用开发传统上以 Java 为主。
3. 大数据：Hadoop、Spark、Flink、Kafka 等大数据生态组件多基于 Java/Scala。
4. 分布式系统与微服务：高并发、高可用系统的常用语言。
5. 金融、电信、电商等行业：银行系统、交易平台等大量采用 Java。
6. 桌面应用：JavaFX、Swing 等 GUI 工具包。

六、相关概念
- JDK（Java Development Kit）：Java 开发工具包，包含编译器、调试工具和 JRE。
- JRE（Java Runtime Environment）：Java 运行环境，包含 JVM 和核心类库。
- JVM（Java Virtual Machine）：Java 虚拟机，负责执行字节码。
- 三者关系：JDK ⊃ JRE ⊃ JVM。

七、总结
Java 凭借其跨平台、稳定、生态丰富等优势，成为世界上使用最广泛的编程语言之一，常年位居 TIOBE 等编程语言排行榜前列，是企业级开发和大型系统建设的首选语言之一。
